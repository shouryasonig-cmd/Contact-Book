# 📒 My Contact Book (Python)

A simple command-line based Contact Book application developed using Python. This project allows users to manage their contacts by performing basic operations like adding, deleting, updating and viewing contact details.

## 🚀 Features

- **Create Contact:** Add a new contact with name, phone number and email.
- **Delete Contact:** Remove an existing contact from the contact book.
- **Update Contact:** Update the name, phone number or email of an existing contact.
- **View Contact List:** Display all saved contact names.
- **View Contact Details:** View complete information of a selected contact.
- **Exit:** Safely exit the application.

## 🛠️ Technologies Used

- Python 3
- Dictionary
- Nested Dictionary
- While Loop
- For Loop
- If-Else Statements
- String Methods
- Basic Dictionary Methods (`pop()`, `items()`)

## 💻 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python contact_book.py
   ```

4. Select an operation from the menu displayed on the screen.

- All contacts are lost when the program is closed.
